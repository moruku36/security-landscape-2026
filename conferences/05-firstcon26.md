# FIRSTCON26 — 38th Annual FIRST Conference

Source: https://www.first.org/conference/2026/program

Denver, 2026-06-14〜19.

Theme: **Peak Defense: Building Adaptive Systems for Modern Threats**

## Notable themes from the program

- Sunburst lessons from the CISO perspective
- Incident response decision fatigue
- Machine-readable CTI / information exchange
- Vendor-data bias in CTI
- Vulnerability discovery → remediation → secure release
- Cloud under siege / APTs targeting cloud environments
- Insider threat controls
- Ransomware affiliate ecosystem
- Cyber deception / adaptive honeynets
- Psychological safety + high-reliability principles for incident management teams

## Interpretation

FIRSTCON26は、2026年のSecurity Operationsが単なるtooling問題ではないことを示す。

Detectionやautomationが高速化しても、incident commander、analyst、platform team、managementの意思決定系が詰まればresponseは遅れる。

したがって成熟したSecOpsでは、

- Technical telemetry
- Runbook / automation
- Clear decision rights
- Cross-team communication
- Psychological safety

を一つのoperating systemとして設計する必要がある。
