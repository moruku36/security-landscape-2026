# RSAC 2026

Sources:
- https://www.rsaconference.com/events/2026-usa
- https://www.rsaconference.com/library/blog/seven-trends-shaping-rsac-2026-conference-a-preview-of-whats-to-come

San Francisco, 2026-03-23〜26.

## Scale

700+ speakers、31 tracks、570+ sessions、600+ exhibitors規模。

## Major themes

RSAC側がsubmissionから抽出した2026の代表テーマは次の通り。

- Model Context Protocol (MCP)
- Agentic AI
- Vibe coding
- Identity
- Governance
- Security team burnout / human sustainability
- Partnership / cross-functional collaboration


## Interpretation

RSACはresearch exploitの深さより、**Enterprise adoption / Governance / CISO agenda / Market direction**を見る場所として有用。

2026年はAgentic AIを単なる新技術ではなく、Identity・Authorization・Governance問題として扱う流れが明確。

## For Cloud / Enterprise Architecture

MCPやAI Agentを導入すると、AgentがSaaS/Cloud/APIを横断する。したがって設計対象はLLM自体よりも、

```text
Agent Identity
  + Tool Permission
  + Data Scope
  + Approval Boundary
  + Audit Trail
```

になる。
