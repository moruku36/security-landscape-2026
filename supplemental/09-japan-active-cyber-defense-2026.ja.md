# 日本の能動的サイバー防御：2026年10月1日の施行範囲と実務上の論点

[English counterpart](09-japan-active-cyber-defense-2026.md)

- 調査基準日：2026年9月30日
- 対象地域：日本
- 分類：法制度・国家サイバー防御・重要インフラ
- 検証方針：政府・国会の一次資料を優先し、確認済みの制度と筆者の分析を分離
- 注意：制度調査であり、個別企業への法的助言ではない

## 要旨

**2026年10月1日は、能動的サイバー防御に関する制度の重要な施行日である。ただし、全制度の一斉開始日ではない。** 政令第46号はサイバー対処能力強化法の本則的な施行日を同日に指定している一方、法律附則は段階施行を定める。官民連携と警察・自衛隊のアクセス・無害化措置が今回の中心で、通信情報を取得・選別・分析する新制度は別の施行段階に属する。[施行期日政令](https://www.cao.go.jp/cybersecurity/pdf/sekoukijitsu.pdf)、[2026年7月31日・首相官邸](https://www.kantei.go.jp/jp/105/actions/202607/31security.html)

2026年4月28日の政府答弁も、官民連携・アクセス無害化の10月1日施行と、通信情報利用の「来年秋まで」の施行準備を区別している。したがって、「明日からすべての通信監視が始まる」といった説明は不正確である。今回確認した資料では、通信情報利用について確定した個別の施行日までは確認できなかった。[衆議院本会議・政府答弁](https://www.shugiin.go.jp/internet/itdb_kaigiroku.nsf/html/kaigiroku/000122120260428016.htm)

## 1. 対象となる法律

「能動的サイバー防御法」は一般的な呼び方であり、中心となる正式な法律は次の2本である。

1. 重要電子計算機に対する不正な行為による被害の防止に関する法律（令和7年法律第42号）。通称「サイバー対処能力強化法」
2. 重要電子計算機に対する不正な行為による被害の防止に関する法律の施行に伴う関係法律の整備等に関する法律（令和7年法律第43号）。通称「サイバー対処能力強化法整備法」

いずれも2025年5月23日公布。前者が報告・情報共有・通信情報利用などを設け、後者が警察官職務執行法、自衛隊法、サイバーセキュリティ基本法などを改正する。[内閣府・法令一覧](https://www.cao.go.jp/cybersecurity/index.html)

## 2. 施行時系列：10月1日に何が変わるか

| 時点 | 内容 | 読み取り上の注意 |
|---|---|---|
| 2025年7月1日 | 総則・基本方針関係などの先行施行 | 法制度の準備は2026年10月以前から始まっている |
| 2025年7月 | 国家サイバー統括室（NCO）発足 | NISCの発展的改組であり、10月1日の新設ではない |
| 2026年4月1日 | サイバー通信情報監理委員会の設置段階 | 監督組織の設置と、全監督対象制度の開始は別 |
| **2026年10月1日** | **官民連携、対象事業者の届出・報告制度、アクセス・無害化措置等** | **本法附則の例外に属する通信情報利用まで一括施行されるわけではない** |
| 後続段階 | 通信情報の取得・取扱い等 | 附則は公布後2年6月以内の政令指定日と規定。具体日について本調査では未確認 |

先行施行の根拠は[2025年6月20日・大臣会見](https://www.digital.go.jp/speech/minister-250620-01)、NCOの沿革は[同室の公式概要](https://www.cyber.go.jp/about/overview/index.html)、監理委員会の設置日は[2025年12月23日・大臣会見](https://www.digital.go.jp/speech/minister-251223-01)参照。法律の段階施行は[本法附則第1条](https://www.shugiin.go.jp/internet/itdb_housei.nsf/html/housei/21720250523042.htm)による。

また、重要インフラの分野横断的な対策について、重要インフラ統一基準と安全基準等策定ガイドラインも2026年10月1日施行予定と公表されている。これらは政府施策・分野別基準の整合を進める枠組みであり、個々の企業の法定報告対象を直接説明する際には、本法の事業者・設備の定義と区別する必要がある。[国家サイバー統括室・重要インフラ対策](https://www.cyber.go.jp/policy/group/infra/policy.html)

## 3. 官民連携と企業の義務

### 確認済みの制度

新たな届出・報告義務の主体は、法律上の「特別社会基盤事業者」である。経済安全保障推進法上の「特定社会基盤事業者」のうち、所定の「特定重要電子計算機」を使用する者という限定がある。「日本の全企業」「すべての重要インフラ関係企業」と同義ではない。

- 対象計算機の導入・変更等に関する届出
- 対象計算機の特定侵害事象、または省令で定めるその原因となり得る事象を認知した場合の報告
- 所管大臣による是正命令や、必要な報告・資料提出要求への対応

根拠は本法第2条第3項、第4〜10条。未報告だから直ちに一律200万円の罰金になる、という理解は避けるべきであり、第83条の200万円以下の罰金は第6条の命令違反に対応する。[法律本文](https://www.shugiin.go.jp/internet/itdb_housei.nsf/html/housei/21720250523042.htm)

**施行時点で導入済みの対象資産は、届出に6か月の経過措置があり、政府の意見募集回答は2027年3月31日までと説明している。** この猶予は既導入資産の届出についてのものなので、インシデント報告まで一律6か月待てると解釈してはならない。[命令案に対する政府回答](https://public-comment.e-gov.go.jp/pcm/download?seqNo=0000315045)

加えて、協議会による情報共有、政府からの分析情報・脆弱性情報の提供、供給者への対応要請を整備する。協議会への参加や通信情報提供に係る協定と、法定のインシデント報告義務は別の仕組みである。[内閣府・制度説明資料、9〜17ページ](https://www.cao.go.jp/cybersecurity/pdf/setsumei.pdf)

### 実務上の提案（分析）

対象となり得る企業は、最初に法務・所管省庁窓口と対象事業・対象資産を照合すべきである。その上で、CSIRT、SOC、設備運用、委託先、法務の間で「誰が事象を認知し、誰が報告を判断するか」を固定する。個人情報保護法や業法上の報告とは別に適用関係を点検し、新制度への報告だけで他制度の義務を充足したと扱わないことが重要になる。既存法の併存については[NCO・関係法令Q&A](https://security-portal.cyber.go.jp/guidance/law-handbook/v2-03.html)が参考になる。

本調査では、報告命令の最新全文を取得できなかったため、一律の「24時間」「72時間」などの期限は記載しない。実際の運用前に[内閣府掲載の現行命令・様式](https://www.cao.go.jp/cybersecurity/index.html)と所管省庁の案内を確認する必要がある。

## 4. アクセス・無害化措置は何を可能にするか

### 確認済みの制度

警察では、警察庁長官が指名する執行官が、重大な危害のおそれと緊急の必要などの要件の下で、攻撃関係の計算機の管理者への措置命令や、自らの危害防止措置を行える。対象は危害防止に通常必要な範囲であり、一般企業に「反撃の権利」を与える制度ではない。[警察庁・令和7年警察白書](https://www.npa.go.jp/hakusyo/r07/honbun/html/bb3321000.html)

改正警察官職務執行法第6条の2は、原則として監理委員会の事前承認を要求する。承認を待つ時間がない特段の事情がある場合には例外があるが、事後の速やかな通知と委員会の確認・必要な勧告が伴う。国内設置と認める相当な理由のない計算機への措置は警察庁の執行官に限定され、外務大臣との事前協議も必要となる。

自衛隊の新たな通信防護措置には、国外の者による高度に組織的・計画的な行為、重大な支障のおそれ、自衛隊の技術・情報の不可欠性、国家公安委員会の要請または同意などの要件がある。首相の命令の下、警察と共同して実施する。[整備法第2条・第4条](https://www.shugiin.go.jp/internet/itdb_housei.nsf/html/housei/21720250523043.htm)

### 評価上の論点（分析）

法的な実施権限と、現場で安全に使える能力は別である。攻撃元に見えるサーバが第三者の侵害済みサーバである場合、誤認や副作用が起こり得る。評価には、対象の特定精度、正当なサービスへの影響、国外関係機関との調整、例外的な事後審査の利用状況が必要になる。施行だけから実運用の成功や攻撃抑止効果を断定することはできない。

## 5. 通信情報利用と通信の秘密

### 制度設計として確認できること

後続段階の通信情報利用には、事業者等との協定による取得と、監理委員会の承認による国外関係通信の取得がある。対象となる通信の類型は、国内を経由する国外間通信、国外から国内、国内から国外の通信で、それぞれ要件が設定される。

取得と分析を同一視してはならない。制度は、取得した通信情報から人が内容を知得しない自動処理で攻撃に関係する機械的情報を選び、それ以外を直ちに消去する構造を採る。機械的情報にはIPアドレスや指令情報などが含まれる。したがって「取得段階から常にメタデータだけ」「メール本文を自由に読める」のいずれも制度の正確な説明ではない。[衆議院調査資料・通信情報利用の整理](https://www.shugiin.go.jp/internet/itdb_rchome.nsf/html/rchome/shiryo/2025ron22-all.pdf/%24File/2025ron22-all.pdf)

監理委員会は、独立した立場で審査・検査を行う機関である。国外関係通信取得の審査・承認、通信情報取扱いの継続的検査、違反への通知・懲戒要求・勧告、アクセス・無害化の審査を所掌する。[サイバー通信情報監理委員会公式サイト](https://www.aoc.go.jp/)

### 市民・利用者への含意（分析）

通常の個人利用者に、この制度に基づく一律の新規届出や端末設定変更が必要になるという根拠は確認していない。一方、国内利用者でも海外サービスを使う通信は国外関係通信となり得るため、「日本に住んでいれば無関係」ともいえない。

通信の秘密を守る仕組みが法定されていることと、運用で十分に機能することは別の検証課題である。今後は、自動選別の精度、情報保持・消去、アクセス記録、第三者提供、監理委員会の検査結果・国会報告の具体性を確認すべきである。本報告は適法性や違憲性を最終判断するものではない。

## 6. 研究上の見立てと今後の確認項目

**見立て（分析）：** 2026年10月は、国家の防御権限と民間の情報共有・報告を接続する節目である。通信情報利用の全面的な準備が終わるまで制度全体が停止しているわけではなく、逆に10月1日だけで全機能が完成するわけでもない。評価単位は「能動的防御が始まったか」という二択より、施行済みの機能、実際の運用、監督の実績に分ける方が有用である。

今後の更新対象：

1. 通信情報利用部分の施行期日政令と関連規則
2. 官民協議会の運用資料、対象資産・報告手順の最新案内
3. 監理委員会の審査・事後確認・検査と公表実績
4. 誤認・付随影響への対応、国外との調整の説明
5. 情報共有が実際の検知・封じ込め時間短縮につながったかを示す検証可能な指標

### Enterprise Security Architectureへの示唆（分析）

以下はリポジトリ側の設計提案であり、法令がこれらの技術的統制を個別に義務付けるとの主張ではない。

| Security Plane | 実務上の準備 |
|---|---|
| Identity / Control | 報告要否の判断、情報開示の承認、対処調整の権限を明確化する |
| Data | 資産情報・インシデント情報の機微性に応じて取扱いを制御し、必要な範囲で共有する |
| Telemetry | 認知・エスカレーション・報告判断の履歴と、利用可能な事象証跡を残す |
| Recovery | 封じ込め・サービス復旧と、報告・政府機関との連携を調整する |

本補足資料は、法施行だけを理由に年次脅威レポートのConsensus MatrixやATT&CK対応を変更するものではない。

## 7. 証拠の限界

- 調査の起点となった[Livedoor記事](https://news.livedoor.com/article/detail/32451445/)は、本調査の取得環境では本文を取得できなかった。記事の見出し、発言者、掲載時刻、本文の正確な主張は未検証であり、記事内容を読んだものとして要約していない。
- 10月1日の施行範囲は、記事とは独立に、政令・法律・官邸発言・国会答弁で照合した。
- 官邸の2026年7月31日ページは検索サービスが返した公式ページの本文で確認したが、直接取得は失敗した。将来のリンク切れ・再取得時には、法律附則と国会答弁によって施行範囲を再確認する必要がある。
- 本報告の「明日」に相当する日は**2026年10月1日**である。後から読む場合もこの絶対日付を使用する。
- 調査基準日現在の実施件数、具体的な作戦内容、人員充足率、誤検知率は確認していない。法定制度の存在を運用実績と混同していない。
- 対象企業数や分野数は改定・指定の影響を受けるため、最新の指定一覧を十分確認できない数字は採用していない。
- 官民報告に関する現行命令の細目は取得上の制約が残る。個別の期限・例外・対象機器判定は、法令全文と所管省庁資料による追加確認が必要である。
