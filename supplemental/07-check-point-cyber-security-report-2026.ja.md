# Check Point Cyber Security Report 2026 — 日本語解説

[English](07-check-point-cyber-security-report-2026.md)

## 追加する価値

Check PointはCore Reportと重なる部分もありますが、**AI Governance / MCP / Edge Device / Geopolitics / Ransomware Fragmentation**について2026年の具体的Signalを補います。

## 主要データ

- Risky AI Promptが2025年に**97%増**。
- Check Pointの該当Researchでは**分析MCPの40%がVulnerable**。
- AIがSocial Engineering / Recon / Targeting / Malware Developmentを高速化。
- RansomwareはDecentralized OperatorとData-only Extortionへ。
- Router / Gateway / VPN ApplianceがHigh-value Initial Access Target。
- Chinese-nexus ActorはEdge/PerimeterでZero-day / One-day WeaponizationをIndustrialize。
- Cloud / SaaS / Edge / On-prem / Identity / Humanを跨ぐAttack Pathが増加。

## Architecture上の意味

### AI GovernanceはPolicyだけでなくTelemetry

見るべきもの:

- Approved / Unapproved AI Tool
- Promptへ投入されるData Class
- Connector
- Agent/Tool Permission
- Policy Violation
- Data Loss

### MCPはExecutable Integration

MCP ServerはAPI / Service Account / Browser Extension / CI/CD Integrationと同じくInventory・Owner・Version・Permissionが必要です。

### Edgeは依然Blind Spot

Router/VPN/GatewayはEDRがなくても、Inventory / Patch / Log / Threat Hunt対象です。

## 優先アクション

- Enterprise AI Usage Discovery
- MCP Server / Tool Registry
- EdgeをExposure/Telemetry Programへ
- Hybrid Attack Pathを横断Model化
- Ransomware DetectionをEncryptionだけでなくIdentity/Data Theft/Extortionへ
